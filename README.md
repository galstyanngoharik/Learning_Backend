# 🚀 Learning Backend

This repository contains my notes, practice exercises, and projects while learning backend development with Node.js.

---

## 📚 Topics Covered

- Node.js Fundamentals & HTTP Module
- Backend Architecture & RESTful API Design
- Express.js (Routing, Middlewares, Static Files)
- Data Persistence & File Operations
- MongoDB & Mongoose (NoSQL)
- SQL & Sequelize (Relational Databases)
- Authentication & Authorization
- Real-Time Communication with WebSockets
- Monolithic vs. Microservices Architecture
- Testing & Production Deployment

---

## 🛠 Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Databases:** MongoDB, SQL (PostgreSQL/MySQL)
- **ODMs/ORMs:** Mongoose, Sequelize
- **Tools:** Postman, WebSockets, Git, GitHub

---

By the end of this course, I will be able to:

- ✅ Build robust RESTful APIs with Express.js
- ✅ Work with both NoSQL (MongoDB) and Relational (SQL) databases
- ✅ Implement secure Authentication & Authorization mechanisms
- ✅ Build real-time applications using WebSockets
- ✅ Design scalable monolithic and microservices architectures
- ✅ Deploy and maintain backend services in production
